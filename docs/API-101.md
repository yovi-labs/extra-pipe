# 101-pipe preview API details

Status: Sprint 2 review, not published. The website contains 101 canonical pipes and four separately counted aliases. The 67 additions below have standalone classes and reusable same-name functions. Existing 34 APIs retain their documented contracts. See [shared contracts](PIPE-101-CONTRACTS.md) and the [canonical inventory backlog](PIPE-101-BACKLOG.json).

## text

### wordCount · WordCountPipe

Content word counters using locale segmentation.

```ts
wordCount(value: string | null | undefined, locale = 'en-US'): number | null
```

Word-like tokens only; punctuation and emoji are not words. Native Intl word segmentation has a Unicode letter/number fallback that is not equivalent for unspaced languages.

Invalid result: `null`. Injected LOCALE_ID; optional override. Helpers default to en-US. Input arrays, objects and Dates are never mutated.

### truncateWords · TruncateWordsPipe

Article previews cut at word boundaries.

```ts
truncateWords(value: string | null | undefined, maximumWords = 20, suffix = '…', locale = 'en-US'): string
```

Maximum 0–100,000 words. Keeps original text when it fits; otherwise appends the suffix after the final whole word. Zero returns empty text.

Invalid result: `""`. Injected LOCALE_ID; optional override. Helpers default to en-US. Input arrays, objects and Dates are never mutated.

### wrapWords · WrapWordsPipe

Plain-text messages wrap to grapheme-bounded lines.

```ts
wrapWords(value: string | null | undefined, maximumColumns = 80): string
```

Columns 1–10,000 count graphemes. Whitespace between words is normalized; line breaks are retained and overlong words are not split.

Invalid result: `""`. No locale argument. Input arrays, objects and Dates are never mutated.

### readingTime · ReadingTimePipe

Localized article reading estimates.

```ts
readingTime(value: string | null | undefined, wordsPerMinute = 200, locale = 'en-US'): string
```

Rate 1–10,000 words/minute; rounds up estimated minutes. It is an estimate, not a timer or measurement of a person.

Invalid result: `""`. Injected LOCALE_ID; optional override. Helpers default to en-US. Input arrays, objects and Dates are never mutated.

### normalizeWhitespace · NormalizeWhitespacePipe


Collapses JavaScript whitespace and trims; it does not remove markup or sanitize HTML.

Invalid result: `""`. No locale argument. Input arrays, objects and Dates are never mutated.

### stripDiacritics · StripDiacriticsPipe

Latin accent folding for search labels; preserve other scripts.

```ts
stripDiacritics(value: string | null | undefined): string
```

Folds marks attached to Latin letters only; preserves Arabic marks and other scripts.

Invalid result: `""`. No locale argument. Input arrays, objects and Dates are never mutated.

### excerpt · ExcerptPipe

Show a grapheme-safe context window around a literal match.

```ts
excerpt(value: string | null | undefined, query: string, maximumLength = 80, suffix = '…'): string
```

Literal case-sensitive first match; budget 0–10,000 graphemes includes up to two suffix markers. Unmatched queries return empty text; small budgets may cut the query itself.

Invalid result: `""`. No locale argument. Input arrays, objects and Dates are never mutated.

### highlightMatches · HighlightMatchesPipe

Structured literal search highlights, never HTML.

```ts
highlightMatches(value: string | null | undefined, query: string): MatchSegment[]
```

Non-overlapping literal case-sensitive matches at full grapheme boundaries. Returns text/matched data, never HTML; empty query returns the unmarked text.

Invalid result: `[]`. No locale argument. Input arrays, objects and Dates are never mutated.

### humanizeIdentifier · HumanizeIdentifierPipe

Readable acronym-aware API/schema labels.

```ts
humanizeIdentifier(value: string | null | undefined): string
```

Splits ASCII acronym/camel boundaries and underscores/hyphens; preserves casing and non-Latin text.

Invalid result: `""`. No locale argument. Input arrays, objects and Dates are never mutated.

### escapeRegExp · EscapeRegExpPipe

Turn a search term into literal regex pattern text.

```ts

```

Escapes pattern metacharacters for literal matching; does not generate regex flags, compile a pattern or validate user data.

### graphemeCount · GraphemeCountPipe

User-visible character limits for multilingual fields.

```ts
graphemeCount(value: string | null | undefined): number | null
```

Counts user-perceived characters, including combining marks and emoji sequences; empty text is zero.

Invalid result: `null`. No locale argument. Input arrays, objects and Dates are never mutated.

### splitLines · SplitLinesPipe

Render pasted multiline content as readonly input rows.

```ts

```

Splits CRLF, CR and LF; preserves empty and trailing lines. Empty text produces one empty line.

Invalid result: `[]`. No locale argument. Input arrays, objects and Dates are never mutated.

## collections

### chunk · ChunkPipe

Group cards into fixed-size display rows.

```ts
chunk<T>(value: readonly T[] | null | undefined, size = 2): T[][]
```

Size 1–5,000; retains the final partial chunk and source item identity.

Invalid result: `[]`. No locale argument. Input arrays, objects and Dates are never mutated.

### flatten · FlattenPipe

Present nested lists with explicit bounded depth.

```ts
flatten(value: readonly unknown[] | null | undefined, depth = 1): unknown[]
```

Depth 0–8; copies the outer array, preserves deeper arrays after the depth limit. Cycles encountered during traversal reject the input.

Invalid result: `[]`. No locale argument. Input arrays, objects and Dates are never mutated.

### compact · CompactPipe

Drop nullish values while retaining 0 and false.

```ts
compact<T>(value: readonly T[] | null | undefined): NonNullable<T>[]
```

Removes only null and undefined, preserving 0, false, empty text, order and item identity.

Invalid result: `[]`. No locale argument. Input arrays, objects and Dates are never mutated.

### partition · PartitionPipe

Split records into matching and remaining buckets.

```ts
partition<T, K extends keyof T>(value: readonly T[] | null | undefined, key: K, expected: T[K]): PartitionResult<T>
```

Own data field, SameValueZero equality; missing/accessor fields read as undefined. Stable order in matching and remaining arrays.

Invalid result: `{"matching":[],"remaining":[]}`. No locale argument. Input arrays, objects and Dates are never mutated.

### zip · ZipPipe

Pair parallel data series to the shorter length.

```ts
zip<T, U>(value: readonly T[] | null | undefined, other: readonly U[]): [T, U][]
```

Pairs by index up to the shorter array; preserves source item identity.

Invalid result: `[]`. No locale argument. Input arrays, objects and Dates are never mutated.

### unzip · UnzipPipe

Split paired coordinates into parallel series.

```ts
unzip<T, U>(value: readonly (readonly [T, U])[] | null | undefined): [T[], U[]]
```

Each input must be a two-element tuple; use readonly pairs declared with as const. Empty/invalid input returns two empty arrays.

Invalid result: `[[],[]]`. No locale argument. Input arrays, objects and Dates are never mutated.

### slidingWindow · SlidingWindowPipe

Create overlapping chart/history windows.

```ts
slidingWindow<T>(value: readonly T[] | null | undefined, size = 2, step = 1): T[][]
```

Full windows only; size and step 1–5,000. Work and output scale with window count times size.

Invalid result: `[]`. No locale argument. Input arrays, objects and Dates are never mutated.

### pluck · PluckPipe

Project own direct properties from record lists.

```ts
pluck<T, K extends keyof T>(value: readonly T[] | null | undefined, key: K): (T[K] | undefined)[]
```

Own data fields only; missing/accessor fields produce undefined (JSON displays these array entries as null).

Invalid result: `[]`. No locale argument. Input arrays, objects and Dates are never mutated.

### filterBy · FilterByPipe

Display records with an own property equal to a value.

```ts
filterBy<T, K extends keyof T>(value: readonly T[] | null | undefined, key: K, expected: T[K]): T[]
```

Own data fields with SameValueZero equality; missing/accessor fields read as undefined. Retains source order and identity.

Invalid result: `[]`. No locale argument. Input arrays, objects and Dates are never mutated.

### intersectionBy · IntersectionByPipe

Show records shared between selections by identity key.

```ts
intersectionBy<T, U, K extends keyof T & keyof U>(value: readonly T[] | null | undefined, other: readonly U[], key: K): T[]
```

Distinct keys present on both sides; retains the first left record in left encounter order. Missing keys form one undefined identity.

Invalid result: `[]`. No locale argument. Input arrays, objects and Dates are never mutated.

### differenceBy · DifferenceByPipe

```ts
differenceBy<T, U, K extends keyof T & keyof U>(value: readonly T[] | null | undefined, other: readonly U[], key: K): T[]
```

Distinct left-only keys; retains the first left record in encounter order. Missing keys form one undefined identity.

Invalid result: `[]`. No locale argument. Input arrays, objects and Dates are never mutated.

### unionBy · UnionByPipe

Combine record sets with first-record precedence.

```ts
unionBy<T, U, K extends keyof T & keyof U>(value: readonly T[] | null | undefined, other: readonly U[], key: K): (T | U)[]
```

Distinct keys; first record wins, visiting left before right. Missing keys form one undefined identity.

Invalid result: `[]`. No locale argument. Input arrays, objects and Dates are never mutated.

### symmetricDifferenceBy · SymmetricDifferenceByPipe

Show records exclusive to either selection.

```ts
symmetricDifferenceBy<T, U, K extends keyof T & keyof U>(value: readonly T[] | null | undefined, other: readonly U[], key: K): (T | U)[]
```

Distinct keys found on one side only; left-only before right-only, first record wins. Missing keys form one undefined identity.

Invalid result: `[]`. No locale argument. Input arrays, objects and Dates are never mutated.

### indexBy · IndexByPipe

Build a prototype-safe lookup Map from records.

```ts
indexBy<T, K extends keyof T>(value: readonly T[] | null | undefined, key: K): Map<T[K] | undefined, T>
```

Map of own keys, last record wins without moving the key's encounter position. Missing keys use undefined. Use KeyValuePipe with a comparator returning zero and JsonPipe to preserve display order across Angular 17–22.

Invalid result: `[]`. No locale argument. Input arrays, objects and Dates are never mutated.

### countBy · CountByPipe

Summarize category frequencies without retaining grouped arrays.

```ts
countBy<T, K extends keyof T>(value: readonly T[] | null | undefined, key: K): CountGroup<T[K] | undefined>[]
```

Counts SameValueZero own-field groups in first-key encounter order. Missing keys use undefined.

Invalid result: `[]`. No locale argument. Input arrays, objects and Dates are never mutated.

### mergeBy · MergeByPipe

Reconcile partial records with shallow last-field precedence.

```ts
mergeBy<T, U, K extends keyof T & keyof U>(value: readonly T[] | null | undefined, other: readonly U[], key: K): (T | U)[]
```

Shallow last-field-wins merge by own identity; first-key order, missing identities reject input. Unchanged source objects are not mutated.

Invalid result: `[]`. No locale argument. Input arrays, objects and Dates are never mutated.

### paginate · PaginatePipe

Generate page items and total-page metadata for client display.

```ts
paginate<T>(value: readonly T[] | null | undefined, page = 1, pageSize = 20): PageResult<T> | null
```

One-based page; size 1–5,000. Returns metadata plus a new items array; out-of-range pages have no items. Invalid input returns null.

Invalid result: `null`. No locale argument. Input arrays, objects and Dates are never mutated.

Key array up to 32 segments; own data only. Forbids **proto**, constructor and prototype. Missing paths use the fallback; an empty path returns the input. Apply JsonPipe yourself for object-valued leaves.

### omit · OmitPipe

Plain records and string keys only; excludes listed enumerable own data fields without traversing paths.

Shallow own-string-key mapping. Colliding targets or non-string mappings reject the input; output keys are prototype-safe data.

### defaults · DefaultsPipe

Fill only nullish own fields from shallow defaults.

```ts
defaults<T extends object, U extends object>(value: T | null | undefined, fallback: U): DefaultsResult<T, U> | null
```

Shallow fallback only for absent/null/undefined fields; preserves 0, false and empty text. Copies enumerable own data fields; result type permits absent structural keys.

### invertRecord · InvertRecordPipe

```ts
invertRecord(value: Readonly<Record<string, string | number | boolean>> | null | undefined): Record<string,string[]> | null
```

Finite number, string or boolean values become string keys; duplicate values collect original field names in encounter order.

Invalid result: `null`. No locale argument. Input arrays, objects and Dates are never mutated.

### pruneEmpty · PruneEmptyPipe

Remove recursively empty data while preserving zero and false.

```ts
pruneEmpty(value: Readonly<Record<string,unknown>> | null | undefined): Record<string,unknown> | null
```

Recursively removes null/undefined/empty text and empty containers, keeping 0/false. Depth 12, cycles reject input. Other leaf objects retain identity.

Invalid result: `null`. No locale argument. Input arrays, objects and Dates are never mutated.

### pathEntries · PathEntriesPipe

Flatten own leaf values to key-array paths, without dotted-key ambiguity.

```ts
pathEntries(value: Readonly<Record<string,unknown>> | null | undefined): PathEntry[]
```

Plain-record root, nested plain records/arrays, enumerable own data fields. Key-array paths preserve literal dots; depth 12/cycles are rejected. Empty containers are leaves.

Invalid result: `[]`. No locale argument. Input arrays, objects and Dates are never mutated.
